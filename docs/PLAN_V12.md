# Plan de trabajo EduEval v12

## Objetivo

Construir una base confiable para que el contenido docente pueda convertirse en actividades válidas sin relaciones inventadas ni respuestas asignadas por posición.

## Fases

1. Matriz de requisitos de las seis actividades.
2. Auditoría de generadores y editores.
3. Auditoría del motor de respuestas y resultados.
4. Corrección de compatibilidad y validación.
5. Revisión de la skill y del prompt portable.
6. Pruebas con contenidos completos, expositivos e incompletos.

## Criterio de protección

La publicación existente y las copias de referencia permanecen intactas. Ningún despliegue se realiza desde este proyecto sin autorización expresa.
