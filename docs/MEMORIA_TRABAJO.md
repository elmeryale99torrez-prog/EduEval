# Memoria de trabajo EduEval v12

## Decisiones iniciales

- La skill no diseña cursos completos; estructura contenido docente para EduEval.
- La IA externa no genera actividades ni respuestas correctas.
- EduEval valida el JSON y decide la compatibilidad.
- La ausencia de un dato opcional no invalida todo el documento.
- Una categoría sin elementos relacionados no habilita clasificación.
- Una actividad no debe generarse si su estructura correcta no puede construirse sin inventar datos.
